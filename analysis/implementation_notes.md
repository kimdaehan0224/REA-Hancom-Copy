# 타자 연습 웹앱 구현 노트

- 대상: `app/` (HTML/CSS/JavaScript, 빌드 도구 없음)
- 근거 자료
  - `analysis/HncTT80_analysis.md`: REA 정적 분석. 아래 `§` 번호는 이 문서의 절을 가리킵니다.
  - `screenshots/`: 원본 캡처 6장
- 코드 주석 표기
  - **[확인]** 분석에서 관찰한 내용
  - **[추정]** 분석으로 확인하지 못해 캡처나 일반 관행으로 정한 내용
  - **[원본에 없음]** 원본에 없는 기능
  - **[미지원]/[미구현]** 이번에 만들지 않은 기능

## 0. 작업 계획과 진행 순서

1. 캡처 확인 → 공통 코어(한글 분해, 타수·정확도 계산, 저장소, 화상 키보드, 셸/라우터)
2. 시작 화면 → 자리연습 안내 → 자리연습 → 낱말연습 → 짧은글 → 긴글 → 결과 창 → 설정/통계
3. 각 화면을 브라우저(`python -m http.server`)에서 열고 다음을 확인한 뒤 다음 화면으로 넘어감
   - 키 입력·IME 조합 이벤트를 합성해서 수치를 확인
   - 스크린샷으로 레이아웃을 확인

### 2.2 한글 조합 입력 (`core/typingInput.js`)

- `compositionstart` / `compositionend` / `input(isComposing)`로 조합 중인 상태를 추적합니다.
- 조합 중인 마지막 글자는 원본 규칙(앞부분 키 일치)으로 판정합니다.
  - 맞게 조합 중이면 노란 배경(`comp`)으로 표시하고, 오타로 세지 않습니다.
  - 첫 키부터 틀리면 조합 중이어도 오타로 표시합니다.
- 조합 중에 Enter/Space를 누르면 조합이 끝난 뒤(`compositionend`) 제출합니다. 이렇게 해야 마지막 글자가 잘리지 않습니다.
- 다음 키 표시(`metrics.nextKey`)는 "갑"(입력 중) → "가보"(목표)처럼 다음 글자의 초성이 받침으로 들어간 경우도 처리합니다. **[추정: 원본 주황 점 표시를 재현]**

### 2.8 원본에 없는 기능

- **Esc 데모 종료**: 자리·낱말·짧은글·긴글 화면에서 Esc를 누르면 현재까지의 수치로 바로 결과 창을 띄웁니다.
  - 결과 창에 "Esc 키로 중단한 데모 결과입니다. (원본에 없는 기능)"을 표시하고, 연습 기록 목록에도 "(데모)"로 남깁니다.
  - 저장 조건은 원래 규칙을 그대로 적용합니다. 예를 들어 짧은글은 11초 미만이면 저장하지 않습니다.
- 결과 창에 저장하지 않은 이유(저장 조건)를 한 줄 안내합니다.
- 긴 글 "글 선택" 목록: 원본의 "긴글 불러오기"(62141)에 해당하는 기능을 단순화했습니다.

### 2.9 콘텐츠 대체 (요청 사항)

- 원본 연습 문장·캡처의 문장은 쓰지 않았습니다.
  - 낱말: 일반 단어 110여 개
  - 짧은 글: 널리 알려진 속담·격언 40개(한국어)와 35개(영어)
  - 긴 글: 직접 지은 문단 3편(한국어)과 1편(영어)
- 캐릭터·로고·배경 그림 대신 원형 이니셜 배지, 하늘/언덕 그라데이션, 도형 아이콘을 썼습니다.
- 앱 이름은 "타자 연습"으로 하고, 원본 제품명·브랜드 표기와 "(웹)" 링크 버튼은 넣지 않았습니다.
