# 원본 기능 대비 구현 비교표

표기: O = 구현, △ = 일부 구현 또는 추정 구현, X = 구현하지 않음

| 원본 기능 | 구현 여부 | 비고 |
|---|:---:|---|
| 사용자 목록·등록·편집·삭제 | O | 검증 문구는 원본 리소스와 같음 (100~800 / 80~100 / 같은 이름 / 최소 1명) |
| 시작 화면 | O | 캐릭터·로고 없이 도형/그라데이션 |
| 상단 탭(자리/낱말/짧은글/긴글) 화면 전환 | O | 전환 흐름은 캡처 기준 추정 |
| 상단 사용자 배지 | △ | 아바타 그림 대신 이니셜. 숫자는 평균타수로 추정 |
| 자리연습 안내(키보드, 1~8단계, 상태줄) | O | 상태줄 형식 확인. 2~8단계 키 구성은 추정 |
| 자리연습(진행도·오타수·정확도, 글자 흐름, 다음 키, 단계 설정) | O | 정확도 미달 시 재연습 문구 확인. 40글자/판·승급 규칙은 추정 |
| 손가락 운지선 그림(캡처의 손 모양 선) | X | 그림 대신 다음 키 주황 점과 Shift 강조만 |
| 낱말연습(이전/현재/다음, 화상 키보드, 단계) | O | 20낱말/판, Enter·Space 제출, 단계 규칙 추정 |
| 짧은글연습(진행도·현재·최고·목표타수·정확도, 다음 문장) | O | 32문장, 누적 평균, 11초 저장 조건 모두 분석으로 확인 |
| 긴글연습(정확도·현재타수·쪽수·타이머·줄 입력) | O | 5줄/쪽 추정, 한 쪽 완료 시 결과(추정), 저장 조건 100타·10초 확인 |
| 긴글 불러오기(사용자 글 추가, NewTitles.dat) | △ | 내장 글 선택만 가능, 사용자 글 추가는 없음 |
| 타수 계산(두벌식 키 입력 단위) | O | CKor2Bul 분해표 그대로 (겹모음/겹받침 2타, 쌍자음 1타) |
| 정확도 계산(글자 단위) | O | FUN_0043cd40 규칙 |
| 한글 조합 중 글자 판정 | O | composition 이벤트 + 원본의 부분 일치 규칙 |
| 결과 창(평균타수·정확도·연습시간·총타수·오타수) | O | 07 캡처의 순위보기·로그인 버튼은 제외 |
| 결과 창 표시 조건 | △ | 자리 40글자/낱말 20개는 추정, 짧은글 32문장은 확인, 긴글 한 쪽은 추정 |
| 기록 저장 조건 | △ | 짧은글 11초·긴글 100타/10초는 확인, 자리·낱말은 추정(1타 이상) |
| 정확도 70%+ 타수 구간(100~500)별 처리 | X | 원본 함수의 의미 미확인 |
| 타자 검정 | X | 긴글 결과 함수 안의 별도 분기로 보이나 미확인 |
| 설정: 사용자 정보·정보 수정 | O | 표시 형식은 리소스 문자열 그대로 |
| 설정: 글자판 두벌식 표준 / 영어 쿼티 | O | |
| 설정: 세벌식 390·순아래·최종, 드보락 | X | 목록에만 "(미지원)"으로 표시 |
| 설정: 소리 켜기/끄기 | △ | 원본 효과음 대신 합성 비프음 |
| 설정: 반복누르기 | △ | 의미 추정(자동 반복 입력 허용 여부) |
| 타자속도 기록 그래프 | △ | 08 캡처가 없어 꺾은선 + 목표선으로 자체 구성 |
| 손가락별 통계 | △ | 표시 형식 확인, 집계 기준 추정 |
| 키별 속도 통계 | O | 60000/간격 누적 평균(46키 테이블 방식) |
| 사용자 초기화 | O | 확인 문구 원본과 같음 |
| 사용자·설정·기록 저장 | △ | localStorage(JSON). 원본 .dat 파일 형식과 호환되지 않음 |
| 영어 연습(자리·낱말·짧은글·긴글) | O | 쿼티 기준, 자체 콘텐츠 |
| 게임: 케이크 던지기 | X | 버튼만, "준비 중" 안내 |
| 게임: 해상구조 SOS | X | 버튼만, "준비 중" 안내 |
| 온라인 대전·로그인·순위 | X | 범위 밖 |
| 원본 연습 문장·이미지·음원 | X | 모두 자체 콘텐츠로 대체(요청 사항) |
| 한컴 타자연습(웹) 링크 버튼 | X | 외부 서비스 링크라 제외 |
| **Esc 데모 종료** | O | **원본에 없는 기능.** 결과 창과 기록에 데모로 표시 |
